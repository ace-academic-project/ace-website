## Requirements
- XAMPP
- PHP
- MySQL

## Installation
1. Clone the repository
2. Place the project in htdocs
3. Start Apache and MySQL in XAMPP
4. Import ace.sql into phpMyAdmin
5. Open localhost/Ace-Website
