# ACE Website

Academic group project developed using HTML, CSS, JavaScript, PHP, and MySQL.

## Project Overview

ACE is a customizable water bottle e-commerce website that allows customers to create personalized water bottles by selecting different bottle colors, cap colors, and icons. Customers can also purchase additional accessories separately, including keychains, bottle boots, ropes, and other add-ons.

## Features

- User registration and login system
- Water bottle customization
  - Bottle color selection
  - Cap color selection
  - Icon selection
- Shopping cart functionality
- Accessory catalog and purchasing
- Order confirmation and checkout process
- Responsive user interface

## Requirements

- XAMPP
- PHP
- MySQL
- Web Browser (Chrome, Edge, Firefox, etc.)

## Installation

1. Clone the repository.
2. Place the project folder inside the `htdocs` directory in XAMPP.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin.
5. Create a database named `acedb`.
6. Import `database/acedb.sql`.
7. Open the website in your browser:

   ```
   http://localhost/Ace-Website
   ```
